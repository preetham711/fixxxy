PROJECT OVERVIEW
================================================================================

FIXXY is a modern, full-stack web application for managing car spare parts,
water wash services, billing, and inventory. Built to replace the original
Python Tkinter desktop application with a professional web-based system.

Technology Stack:
- Backend: FastAPI (Python)
- Frontend: React 18 + Vite
- Database: MySQL 8.0+
- Authentication: JWT with Bcrypt

HOW TO RUN
================================================================================

STEP 1: Setup Database (5 minutes)
--------------------------------------
1. Start MySQL:
   Start-Service -Name MySQL80

2. Create database:
   mysql -u root -p
   CREATE DATABASE fixxy_store;
   EXIT;

3. Import schema:
   cd "c:\Users\preetham\Documents\py pj"
   mysql -u root -p fixxy_store < database\schema.sql

STEP 2: Run Backend (2 minutes)
--------------------------------------
1. Navigate to backend:
   cd backend

2. Install dependencies (first time only):
   pip install -r requirements.txt

3. Configure .env file:
   Copy-Item .env.example .env
   Edit .env and set MYSQL_PASSWORD

4. Start backend:
   uvicorn app.main:app --reload

5. Verify: http://localhost:8000/docs

STEP 3: Run Frontend (2 minutes)
--------------------------------------
1. Open NEW terminal

2. Navigate to frontend:
   cd frontend

3. Install dependencies (first time only):
   npm install

4. Start frontend:
   npm run dev

5. Browser opens automatically at http://localhost:5173

STEP 4: Test Login
--------------------------------------
1. Login as customer (customer / customer123)
   → Should redirect to /dashboard

2. Logout, then login as admin (admin / admin123)
   → Should redirect to /admin

================================================================================
TROUBLESHOOTING
================================================================================

BACKEND WON'T START:
→ Check: Python dependencies installed (pip install -r requirements.txt)
→ Check: .env file exists and has correct MySQL password
→ Check: MySQL service is running (Get-Service MySQL*)

FRONTEND WON'T START:
→ Check: Node modules installed (npm install)
→ Check: Port 5173 is available
→ Check: No JavaScript errors in terminal

CORS ERRORS:
→ Check: Backend .env has CORS_ORIGINS=http://localhost:5173
→ Restart backend after changing .env

LOGIN DOESN'T WORK:
→ Check: Backend is running on port 8000
→ Check: Database has default users
→ Check: Browser console for errors
→ Check: Network tab for API responses

MYSQL CONNECTION FAILS:
→ Check: MySQL is running
→ Check: .env has correct password
→ Test: mysql -u root -p
